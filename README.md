# Jonny

Браузерная версия миниигры «Америкэн бой»: настольное поле, физика кубиков
и рисованный бруклинский порт. Поле и физика — three.js + Rapier,
интерфейс, правила и экономика — HTML/JS поверх него.

## Играть

https://sudarikovandrey.github.io/Jonny/

Открывается в мобильном браузере и на десктопе. Кнопка полного экрана
растягивает поле на всю ширину, интерфейс остаётся колонкой по центру.

## Локально

Через `file://` не работает — нужен HTTP-сервер:

```sh
python3 -m http.server 8766
```

Затем открыть http://localhost:8766/.

## Управление

Перетаскивание — обзор карты, щипок — масштаб. Кубик внизу по центру,
«Джонни» и «Магазин» — окна прокачки и покупок.

## Что здесь

Это собранная версия, а не исходники. Прогресс хранится локально в браузере
(`americanboy_mobile`), сервера и аккаунтов нет.
